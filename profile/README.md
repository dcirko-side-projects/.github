# dcirko-side-projects

A collection of side projects built for personal use, from university and everyday organizers to a planned travel companion.

| Project | What it does |
| --- | --- |
| [Kolegium](https://github.com/dcirko-side-projects/kolegium) | A university organizer for schedules, courses, attendance, and projects, built with Angular and Firebase. |
| [Trenio](https://github.com/dcirko-side-projects/trenio) | A mobile-first organizer for tasks, notes, ideas, and plans, built with React and Supabase. |
| [Higio](https://github.com/dcirko-side-projects/higio) | A local-first tracker for hygiene, routines, supplements, and dog care, built with Expo and React Native. |
| [Tripora](https://github.com/dcirko-side-projects/tripora) | A planned offline-capable mobile companion for shared trips, places, expenses, and memories. |
